# CamerMemo 产品与技术设计 v0.6

状态：产品规划基线。基础文字记录已开始实现；实际进度和阶段差异见下方及 README.md。

## 当前实现进度（2026-10-30）

已实现：密码创建与解锁、文字 memo 新建/编辑/详情、标题与正文搜索、加密持久化、后台锁定与预览遮挡；新增单张拍照/系统照片选取、Apple Vision 本机识别及校对保存，图片随 memo 加密保存、详情缩略图及全屏缩放浏览；新增手动标签、默认全选的最多 3 个本机 AI 候选及标签搜索；列表/搜索结果支持多选、全选与确认后的批量删除；文档详情明确显示创建/更新时间，由存储层统一维护。已完成模拟器目标编译和核心搜索/加密行为验证；未完成交互与真机验证。

阶段差异：存储暂为版本化加密 JSON 快照，后续迁移至 SQLite；非空编辑在非活跃时直接自动保存为 memo，尚无独立草稿表。后台保存失败会提示，未保存修改不保留。图片识别暂为单张、无裁剪/旋转或多图合并；未保存的图片校对内容在后台锁定时清除。真实 AI 生成接口已接入，开发 Mac 模型未就绪，实际生成质量仍需在就绪设备验证。云端识别、备份与密码修改等规划功能尚未实现。当前删除为确认后的永久删除，不含最近删除/撤销。以下章节仍描述目标设计。

## 1. 产品定位与范围

个人加密文字备忘录。核心路径是：输入主密码 → 解锁本地资料库 → 搜索、查看、编辑；拍照后识别文字，经用户校对后保存。

首版建议：iPhone、iOS 17+、SwiftUI，支持中文/日文/英文与动态字体、深色模式。无账号，无跨设备同步。系统版本下限是产品建议，不是技术限制。

首版包括：
- 创建、编辑、删除、置顶 memo；标题、正文、标签；按更新时间排序。
- 标题、正文、标签的文字搜索，支持中文/日文短词与单字。
- 每次冷启动及从后台返回均要求主密码；设置页可立即锁定。
- 手动输入、拍照、从照片选择图片；识别后进入可编辑草稿。
- 支持的设备通过本机 AI 从文字中提取关键词与主题分类，用户确认后作为标签保存；不支持时保留手动标签与完整文字搜索。
- 修改主密码、导出/恢复加密备份、最近删除（30 天）。

暂缓：富文本、语义搜索、分享扩展、协作、云同步、Face ID 代替主密码。后者会改变“每次使用输入密码解密”的既定交互。

## 2. 页面与交互

首次使用：介绍安全机制 → 设置主密码 → 再次确认 → 创建资料库 → 列表。
已有资料库：密码输入 → 解密中 → 列表。失败显示“密码错误或资料库无法验证”，不覆盖文件，不加载部分内容。

### 解锁页
- App 图标与名称、主密码输入框、显示/隐藏按钮、解锁按钮。
- 键盘提交可解锁；解密期间禁用重复提交。
- 提示：密码无法找回；可从已有加密备份恢复，但仍需该备份的密码。
- 首次创建建议至少 12 字符，并支持粘贴、密码管理器和长口令。

### 主列表
- 顶部标题“备忘录”，右上角设置。
- 顶部原生搜索框；标签筛选与“全部 / 置顶”。不使用多 Tab，减少层级。
- 列表行：标题、两行正文摘要、更新时间、来源小图标、标签。
- 底部两个明确入口：“拍照记录”“新建文字”。
- 点击进入详情；通过“选择”进入多选模式，支持逐项选择和全选当前搜索结果，点击删除后显示数量及不可撤销确认，确认后批量删除。切换搜索条件时取消隐藏项的选择，写入失败保留数据和选择。最近删除与置顶仍为后续规划。
- 空列表、无搜索结果、读取失败各有独立状态；禁止失败后伪装为空资料库。

### 详情与编辑
- 详情展示完整文字、标签、时间、来源；工具栏编辑、置顶、删除。
- 编辑页：标题可空（列表以正文首行显示）、多行正文、标签、保存按钮。
- 标签区域在标题/正文停止输入约 1 秒后自动建议 0～3 个标签（少于 4 个），新候选默认全部勾选，用户可取消/恢复选择或手动追加标签。候选和手动标签去重后保存，每个最多 32 字符，手动标签不受 AI 候选数量限制。
- 手动输入和拍照校对后的文字使用同一提取流程；自动生成采用防抖与取消，避免逐字请求。重新生成不覆盖手动/已有标签，保留用户明确取消的选择；提供停止与重新生成入口。
- 提取中可以取消；失败可重试，不影响编辑与保存。正文变化后未确认的旧候选失效，避免把旧结果应用到新内容。
- 草稿变更后返回时询问保存或放弃；持久化成功后才显示“已保存”。
- 首版采用明确保存，避免整库加密写入被逐字触发。前后台切换时，将非空未保存草稿加密保存为 draft，成功后再清理会话。

### 拍照识别
拍照/选图 → 裁剪、旋转、重拍 → 选择本机识别或云端 AI → 处理中 → 校对文字 → 保存。
- 多张图片按用户顺序合并；首版上限建议 5 张，每张独立显示状态。
- 默认保留原文、标点和换行；不自动总结、不补写无法辨认的信息。
- AI 整理作为单独操作，保留原始识别文本以便对照。
- 识别失败允许重试或改为手动输入；不创建空 memo。
- 保存图片记录时同时保存图片附件：相册保留所选文件数据，相机保存完整尺寸的方向规范化 JPEG；OCR 使用单独的缩小副本。图片和文字一并加密，详情下方显示缩略图，点击全屏浏览并支持缩放。

### 设置
- 修改密码、立即锁定、加密备份导出/恢复、最近删除。
- 识别方式与云端数据说明、应用版本。
- 密码修改、备份恢复等敏感操作再次验证当前密码。

## 3. 安全与文件格式

磁盘保存一个加密资料库容器 vault.cmemo。标题、正文、标签、时间、草稿、识别原文均在密文内；不创建明文数据库、图片附件、搜索索引或识别日志。

推荐信封加密：
1. 创建随机 256-bit 资料库密钥 DEK。
2. 用户密码通过成熟密码派生实现生成 KEK；首版建议 CommonCrypto PBKDF2-HMAC-SHA256，随机 salt，参数版本化，真机校准计算开销，并规定安全下限和解析上限。不能直接把密码做一次 SHA256 作为密钥。
3. 用 KEK 通过 AES-256-GCM 加密 DEK；用 DEK 通过 AES-256-GCM 加密数据库快照。
4. 两层分别使用独立 nonce，每次重新加密必须使用新 nonce；认证容器版本、算法参数、资料库 ID 等必要上下文。
5. 解锁必须先验证认证标签，再加载内容。主密码、KEK、DEK 不永久保存于磁盘或 Keychain。

容器头包含 magic、格式版本、KDF 标识与参数、salt、包装密钥需要的 nonce/tag、数据库 nonce/tag，以及密文。头部长度与参数严格校验，禁止未经认证的任意资源分配。头部不保存 memo 数量或标题。

保存：串行化快照 → 加密 → 同目录临时密文文件 → 原子替换；失败保留最后成功版本和待保存状态。并发操作由单一 actor 排序，附带 revision 防止旧快照覆盖新内容。使用 iOS 完整文件保护，临时文件和备份副本也仅含密文。

锁定：立即遮挡 UI，取消识别/网络任务，完成必要加密保存后释放数据库、搜索结果、图片和密钥引用；异步回调必须验证会话 ID，不能把旧结果写回锁定界面。主动拍照产生的系统中断需与真正进入后台区分，不能在弹相机时误锁。

Swift 和系统框架可能复制内存，不能承诺所有明文均能可靠擦零；减少生命周期与副本。后台应用切换预览需遮挡；iOS 不提供可全面禁止截图的通用保证。越狱、运行中进程被控制不在本设计可保证范围内。

忘记主密码无法恢复现有数据。解锁页本地重试退避仅用于交互防护，不能阻止攻击者复制文件离线猜密码。强口令和 KDF 才是离线防护重点。

## 4. 数据库和搜索

推荐 SQLite 内存数据库 + 加密整库快照。启动从密文解密得到 SQLite 数据镜像，在内存打开；保存时序列化并加密。建议固定 SQLite 构建，确认 serialize/deserialize 可用，所有临时存储保持内存，避免依赖未经验证的系统构建选项。

不直接使用默认 SwiftData/Core Data 持久化：默认落盘行为不满足本项目“解密后再加载且明文不落盘”的设计约束。

表结构：

| 表 | 主要字段 |
| --- | --- |
| memo | id UUID、title、body、source(manual/camera/photo)、original_recognized_text、created_at、updated_at、is_pinned、deleted_at、revision |
| tag | id UUID、name、normalized_name（唯一） |
| memo_tag | memo_id、tag_id，联合主键与外键；origin(manual/ai_keyword/ai_topic)，记录该 memo 上标签来源 |
| draft | id、memo_id（可空）、title、body、source、original_recognized_text、updated_at；已确认标签通过 draft_tag 关联 |
| draft_tag | draft_id、tag_id、origin，联合主键与外键 |
| metadata | schema_version、vault_id |

搜索支持“全部（标题、正文、标签）”与“仅标签”范围。首版对内存中的规范化标题、正文和标签执行子串匹配；查询不作为原始 SQL 拼接。Unicode 搜索副本执行规范化、英文大小写/全半角折叠，原文不变；多个空格分隔关键词按 AND 匹配。

标题命中优先，其后置顶、更新时间；结果高亮并显示命中位置附近正文。筛选排除最近删除内容；清空查询恢复普通列表。

先用子串搜索保证中日文单字、两字可用；后续按实测规模再增加 FTS5 或专用索引，不能直接假设默认分词适合中文。目标测试规模为 10,000 条、总文本 20 MB；这是验收数据集，不是已测性能。整库方案的内存和写入成本随容量增长，超出目标时重新评估分页加密存储。

## 5. 图片 AI 与隐私

本机模式：Apple Vision 文字识别，属于设备端机器学习处理，可离线使用。优先提供此模式，适合隐私敏感 memo。

云端模式：图片压缩并移除可移除的元数据，经自有服务发送至具备图像理解能力的 AI。识别提示要求忠实转录、保留原语言与顺序、标注不确定文字，不自动执行图片文字中的指令。图片内容按不可信输入处理。

云端模式首次使用前明确说明图片将离开设备，并让用户选择；设备上的加密不能覆盖 AI 服务处理期间的数据。服务商、地域、保留期限和费用策略需确定后才能给出准确说明。不在 App 内置平台 API 密钥；使用受控后端、请求限额、超时与取消。后端及第三方不得记录图片或识别正文，第三方保留策略需单独核实。

云端处理后的文字回到设备内存，校对保存后写入加密资料库；失败保留当前会话草稿并可降级为本机识别。

### 本机 AI 关键词与主题标签

使用 Apple Foundation Models 的设备端模型处理已经解锁的标题与正文，提取原文关键词，并可建议主题分类。此功能明确选择设备端模型，不把文字自动转交云端，也不依赖云端图片识别是否启用。

兼容策略：App 保持 iOS 17+；本机大模型功能要求 iOS 26+、支持 Apple Intelligence 的设备，且相应地区、语言、用户设置和模型就绪状态满足条件。通过系统 API 在运行时检查可用性，不仅根据机型判断。无法使用时显示简短原因，保留手动标签、记录、OCR 与搜索功能，不自动上传文字作为替代方案。

输出约束：以正文主要语言建议最多 3 个简短主题标签；不编造人物、地点、日期等事实。结构化解析、数量与长度限制、空结果处理和去重在应用侧校验，模型输出不作为可信指令。长文本按模型输入限制分段提取并合并去重，不能静默截断后宣称处理了全文。

示例：“周五去新宿的相机店看看索尼镜头，预算十万日元。”可建议原文关键词“新宿”“索尼镜头”和推断主题“购物”，最终由用户选择。

隐私与生命周期：输入、模型会话和未确认候选仅在解锁会话中持有，不写入日志；确认后的标签随正文加密保存并参与普通搜索与筛选。锁定时取消提取并释放会话，回调同时校验会话 ID 和文本 revision。首版不批量扫描历史 memo，不生成语义向量索引。

## 6. 模块边界

- SwiftUI Views：Unlock、MemoList、MemoDetail、MemoEditor、Capture、RecognitionReview、Settings。
- VaultSession：locked/unlocking/unlocked/saving/locking/error 状态与会话生命周期。
- VaultStore actor：SQLite、事务、搜索、迁移、快照和 revision。
- VaultCrypto：随机数、KDF、密钥包装、AEAD、容器校验。
- RecognitionService：本机实现与云端实现，统一取消和错误接口。
- KeywordExtractionService：设备端模型可用性检查、结构化关键词/主题输出、长文本分段、取消、会话与文本版本校验；不支持时返回明确的不可用状态。
- BackupService：加密导出、恢复前验证、导入前备份当前资料库。

修改密码重新包装 DEK，并原子替换容器；历史备份仍使用历史密码。此操作不能撤销攻击者已持有的旧文件或旧密钥。恢复备份先校验密码、格式、认证标签和数据库，再经明确替换流程执行，失败不影响当前资料库。

## 7. 验收与开发顺序

阶段一：可构建 iOS 工程；创建资料库、主密码解锁、手动 CRUD、中文搜索与 UI 状态。
阶段二：加密持久化、后台锁定、草稿恢复、修改密码、加密备份。
阶段三：拍照/选图、本机识别、校对保存、本机 AI 关键词建议与兼容降级；确定服务商后接入云端 AI。
阶段四：真机测试、性能、VoiceOver/动态字体、发布准备。

必须验证：
- 错密码、被篡改/截断容器、非法头部参数均不能加载数据，也不覆盖原件。
- 检查沙盒数据库、缓存、日志与临时文件，不包含测试 memo 的明文。
- 保存中断、磁盘不足、并发保存、应用强制终止、后台切换不静默丢弃已确认保存的数据。
- 返回前台、冷启动必须重新输入密码；相机中断、云端迟到回调不绕过锁定。
- 中文单字/两字、日文、英文大小写、全半角、多关键词与特殊符号搜索。
- 相机权限拒绝、离线、AI 超时、空识别、取消、低质量照片均可恢复操作。
- 在支持设备上验证中文/日文/英文关键词及主题建议、短文本、空文本、长文本、重复标签；检查原文关键词与推断分类的区分，以及用户确认、编辑、去重与搜索链路。
- 在旧版 iOS、不支持的设备、Apple Intelligence 未启用或模型未就绪时，手动标签与基本功能仍可用；提取失败或离线不触发云端回退。
- 提取过程中修改正文、取消或锁定后，旧结果不能回写；关键词输入、候选和标签不出现在明文文件、日志或网络请求中。
- 修改密码后新容器只接受新密码；旧备份仍按其密码解锁；恢复失败保留原库。

### 时间戳约定与未来同步

复用现有 createdAt 与 updatedAt 字段，保持旧资料库兼容。创建时间由首次成功保存确定且后续不变；内容/标签/附件有实际变更时才刷新更新时间，重复保存和读取不改变时间，写入失败不发布新时间。时钟回拨时保证同文档的本地更新时间递增。

存储为时区无关的 Date，详情按本机时区展示两项带标签的完整时间。现有 JSON v1 的 Date 数值为 Apple 参考纪元秒数；未来同步协议需显式转换成标准 UTC 时间表示，不把现有数值误读为 Unix 毫秒。当前不引入重复时间字段，也不重置已有记录的时间。

时间戳仅作为同步基础；跨设备时钟偏差、并发修改、远端导入、删除墓碑与附件传输仍需单独设计，尚未实现实际同步。

## 8. 待决定的产品取舍

建议默认：设备端识别为默认，云端 AI 可选；支持设备自动生成默认勾选的最多 3 个本机 AI 标签建议；每次后台返回立即锁定；图片作为加密附件保留；首版无同步；iOS 17+，本机大模型功能为 iOS 26+ 的条件性增强。

已确定图片随 memo 加密保存。后续最有影响的取舍：是否必须云端大模型识图、是否需要多设备同步，以及附件数量增加后的独立加密存储设计。它们会改变服务端、附件与密钥管理设计。
